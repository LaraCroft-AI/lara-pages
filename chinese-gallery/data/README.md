# Данные карт

`character-radicals.json` связывает знаки из `vocab_data.json` с их основным словарным ключом. Это проекция полей `character` и `radical` из [Make Me a Hanzi, dictionary.txt](https://github.com/skishore/makemeahanzi/blob/master/dictionary.txt), полученная 16 сентября 2026 года. Исходный справочник основан на Unihan и CJKlib. Лицензия производного файла: LGPL-3.0-or-later; тексты LGPL и GPL находятся в `licenses/`.

Изменения относительно источника: удалены знаки, отсутствующие в словарях уроков, и все поля, кроме основного ключа; JSONL преобразован в JSON-объект. Графические данные и шрифты Make Me a Hanzi не включены. Связь означает основной словарный ключ, а не произвольное графическое сходство. Например, 月 (луна) и ⺼ (плоть) различаются; 心/忄 и 火/灬 объединены в семейства.

Подписи узлов в `../maps-data.js` составлены для проекта. Слова, переводы, пиньинь и уровни берутся только из `../vocab_data.json`; данные сайта-примера не включены. Карты иероглифов находят точное вхождение знака в слово, исключая сам отдельный знак. При добавлении уроков нужно обновить справочник ключей для новых знаков.

Чтобы пересобрать производный файл из загруженного оригинала:

```sh
python3 update_map_radicals.py /path/to/dictionary.txt
```

Скрипт обновления поддерживает символ 〇 как `null` (без назначенного ключа), если он появится в уроках: в исходном справочнике его нет.
