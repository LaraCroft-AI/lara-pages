# Описание проекта для ИИ-агентов

Этот файл — единая документация проекта `chinese-gallery`.

## Правила работы

- Храните все JSON-данные приложения в единственной папке `data` (строчными буквами); файлы npm остаются в корне.
- HTML содержит разметку; логику и обработчики размещайте в `scripts`, стили — в `styles`.
- Поддерживайте описание проекта и происхождение данных в этом `AGENTS.md`, не создавая дублирующих Markdown-файлов.
- Сохраняйте 214 ключей Канси, варианты написания, связи с уроками и совместимость существующих ссылок.
- После изменения путей проверяйте загрузку ресурсов с точным регистром имён. Для функциональных изменений запускайте соответствующие Playwright-тесты на desktop и mobile.
- Сохраняйте лицензии и сведения об источниках данных; не выдумывайте чтения или связи иероглифов.

## Назначение проекта

Статический учебный сайт с двумя разделами:

- **Уроки** (`vocabulary.html#lessons`): выбор нескольких словарей, поиск, озвучка и тренировка в обоих направлениях.
- **Карты** (`vocabulary.html#maps`): связи по основному ключу и по вхождению иероглифа в слово, фильтры HSK 3.0, поиск узлов, озвучка, режим списка и печатные карты/прописи.

## Запуск

```sh
cd chinese-gallery # из корня репозитория; пропустите, если уже в этой папке
python3 -m http.server 8765 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:8765/vocabulary.html`. Страница должна открываться через HTTP, поскольку словари загружаются через `fetch`. Сборка и серверная база данных не нужны. Tailwind и шрифты загружаются с CDN; озвучка зависит от поддержки китайского языка браузером/системой.

## Карты

Данные слов общие с уроками: `data/vocab_data.json` — 14 уроков, 768 слов. Отдельных словарей «HSK 3.0 — Уровень …» нет; метки уровня у слов и фильтры карт сохранены. Отбор уроков не ограничивает карты. Фильтр HSK выбирает **ровно указанный уровень**, «Все» включает также слова вне списка HSK. Используется HSK 3.0, как в существующем словаре.

На карте показываются восемь слов за раз; остальные доступны через «Далее». «Список» отображает всю выборку. На узких экранах список выбран по умолчанию, карта доступна с горизонтальной прокруткой. Нажатие слова показывает полный перевод и запускает озвучку. Ссылку из адресной строки можно сохранить: она содержит тип, узел и уровень. Переход между разделами сохраняет выбранные уроки и текущую тренировку.

«Печатать карту» строит страницы с паутинками для всех выбранных слов, «Печатать прописи» — строки с образцами и клетками. В системном окне печати можно выбрать сохранение в PDF. Это собственные материалы на данных сайта; сторонние авторские PDF не распространяются.

Подписи и семейства ключей находятся в `data/map-catalog.json`. Справочник ключей — `data/character-radicals.json`, происхождение и лицензии описаны ниже. После добавления новых знаков пересоберите справочник скриптом `scripts/update_map_radicals.py`.

## Проверка

```sh
npm ci
npx playwright install chromium
npm test
```

Тесты выполняются на desktop (1280×900) и mobile (Pixel 5). Playwright автоматически запускает локальный HTTP-сервер на порту 8765. В CI (`.github/workflows/tests.yml` в корне репозитория) тесты запускаются при push в `main` и при создании PR; отчёты и снимки сохраняются при ошибке. `tests/vocabulary.spec.js` проверяет уроки; `tests/maps.spec.js` — переходы, связи и фильтры, поиск, пагинацию, отсутствие перекрытий, озвучку, печать и обработку ошибок загрузки.

Если данные не загружаются, проверьте доступность JSON-файлов через HTTP. В разделе «Карты» при ошибке есть кнопка повторной загрузки. Если не слышно произношение, проверьте наличие китайского голоса в системе. Для печати с иероглифами дождитесь загрузки шрифта.

Для пересчёта меток HSK 3.0 у слов используется `node scripts/update_hsk30.js /path/to/hsk30.csv /path/to/hsk30-expanded.csv`. Скрипт обновляет уровни в существующих уроках и не добавляет отдельные словари.

## Структура файлов

- `vocabulary.html` — разметка и подключения внешних файлов, без встроенных скриптов, стилей и обработчиков событий.
- `scripts/vocabulary.js` — уроки, карточки, поиск, озвучка и тренировки.
- `scripts/maps.js` — карты и связи иероглифов; оба браузерных скрипта подключаются в конце страницы в указанном в HTML порядке.
- `styles/vocabulary.css`, `styles/sections.css` — оформление уроков и карт. Порядок CSS-подключений сохраняет каскад исходной страницы.
- `data/vocab_data.json` — словари уроков; `data/character-radicals.json` — словарные ключи; `data/map-catalog.json` — каталог всех 214 ключей Канси и подписи иероглифов.
- `data/licenses/` — тексты лицензий данных.
- `scripts/update_hsk30.js`, `scripts/update_map_radicals.py` — обновление данных; пути по умолчанию определяются относительно скриптов и не зависят от текущей папки.
- `tests/`, `playwright.config.js`, `package.json`, `package-lock.json` — тесты и служебные файлы npm. JSON-конфигурация npm остаётся в корне.

Папка `data` пишется строчными буквами: это важно при размещении на сервере с учётом регистра путей. Для пересборки связей из корня проекта: `python3 scripts/update_map_radicals.py /path/to/dictionary.txt`.

## Происхождение данных

`character-radicals.json` связывает знаки из `vocab_data.json` с их основным словарным ключом. Это проекция полей `character` и `radical` из [Make Me a Hanzi, dictionary.txt](https://github.com/skishore/makemeahanzi/blob/master/dictionary.txt), полученная 16 сентября 2026 года. Исходный справочник основан на Unihan и CJKlib. Лицензия производного файла: LGPL-3.0-or-later; тексты LGPL и GPL находятся в `data/licenses/`.

Изменения относительно источника: удалены знаки, отсутствующие в словарях уроков, и все поля, кроме основного ключа; JSONL преобразован в JSON-объект. Для 阝 по полю `decomposition` восстановлен ключ: слева — 阜 (холм), справа — 邑 (город); при неоднозначной структуре скрипт останавливается. Проекция обновлена 17 сентября 2026 года. Графические данные и шрифты Make Me a Hanzi не включены. Связь означает основной словарный ключ, а не произвольное графическое сходство. Например, 月 (луна) и 肉/⺼ (плоть) различаются; 心/忄 и 火/灬 объединены в семейства.

`map-catalog.json` содержит все 214 ключей Канси: основную форму, пиньинь, русское значение, семейство форм, номер и число черт основной формы. Нумерация и основные формы соответствуют [Unicode CJKRadicals.txt](https://www.unicode.org/Public/UCD/latest/ucd/CJKRadicals.txt); число черт следует традиционным группам Канси (1–17). Русские подписи составлены для проекта. Варианты не увеличивают число ключей: например, 水/氵/氺 — один ключ №85, а 糸/糹/纟 — №120. Для поиска 阝 показаны оба семейства; связь конкретного иероглифа определяется положением компонента, а не совпадением начертания.

Слова, переводы, пиньинь слов и уровни берутся только из `vocab_data.json`; данные сайта-примера не включены. Карты иероглифов находят точное вхождение знака в слово, исключая сам отдельный знак. Каталог иероглифов включает каждый знак из уроков; если отдельного чтения и перевода нет, они не извлекаются из многосложного слова. Ключи без примеров остаются доступны, но печать слов для них отключена. Связанные иероглифы учитывают фильтр HSK; переходы ключ → иероглиф → ключ сохраняют этот фильтр. При добавлении уроков нужно обновить справочник ключей для новых знаков.

Чтобы пересобрать производный файл из загруженного оригинала, выполните из корня проекта:

```sh
python3 scripts/update_map_radicals.py /path/to/dictionary.txt
```

Скрипт обновления поддерживает символ 〇 как `null` (без назначенного ключа), если он появится в уроках: в исходном справочнике его нет.
