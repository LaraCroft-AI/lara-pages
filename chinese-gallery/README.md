# Китайский язык

Статический учебный сайт с двумя разделами:

- **Уроки** (`vocabulary.html#lessons`): выбор нескольких словарей, поиск, озвучка и тренировка в обоих направлениях.
- **Карты** (`vocabulary.html#maps`): связи по основному ключу и по вхождению иероглифа в слово, фильтры HSK 3.0, поиск узлов, озвучка, режим списка и печатные карты/прописи.

## Запуск

```sh
cd chinese-gallery # из корня репозитория; пропустите, если уже в этой папке
python3 -m http.server 8765 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:8765/vocabulary.html`. Страница должна открываться через HTTP, поскольку словари загружаются через `fetch`. Сборка и серверная база данных не нужны. Tailwind и шрифты загружаются с CDN; озвучка зависит от поддержки китайского языка браузером/системой.

## Карты

Данные слов общие с уроками: `vocab_data.json` — 14 уроков, 768 слов. Отдельных словарей «HSK 3.0 — Уровень …» нет; метки уровня у слов и фильтры карт сохранены. Отбор уроков не ограничивает карты. Фильтр HSK выбирает **ровно указанный уровень**, «Все» включает также слова вне списка HSK. Используется HSK 3.0, как в существующем словаре.

На карте показываются восемь слов за раз; остальные доступны через «Далее». «Список» отображает всю выборку. На узких экранах список выбран по умолчанию, карта доступна с горизонтальной прокруткой. Нажатие слова показывает полный перевод и запускает озвучку. Ссылку из адресной строки можно сохранить: она содержит тип, узел и уровень. Переход между разделами сохраняет выбранные уроки и текущую тренировку.

«Печатать карту» строит страницы с паутинками для всех выбранных слов, «Печатать прописи» — строки с образцами и клетками. В системном окне печати можно выбрать сохранение в PDF. Это собственные материалы на данных сайта; сторонние авторские PDF не распространяются.

Подписи и семейства ключей находятся в `maps-data.js`. Справочник ключей — `data/character-radicals.json`, происхождение и лицензии описаны в `data/README.md`. После добавления новых знаков пересоберите справочник скриптом `update_map_radicals.py`.

## Проверка

```sh
npm ci
npx playwright install chromium
npm test
```

Тесты выполняются на desktop (1280×900) и mobile (Pixel 5). Playwright автоматически запускает локальный HTTP-сервер на порту 8765. В CI (`.github/workflows/tests.yml` в корне репозитория) тесты запускаются при push в `main` и при создании PR; отчёты и снимки сохраняются при ошибке. `tests/vocabulary.spec.js` проверяет уроки; `tests/maps.spec.js` — переходы, связи и фильтры, поиск, пагинацию, отсутствие перекрытий, озвучку, печать и обработку ошибок загрузки.

Если данные не загружаются, проверьте доступность JSON-файлов через HTTP. В разделе «Карты» при ошибке есть кнопка повторной загрузки. Если не слышно произношение, проверьте наличие китайского голоса в системе. Для печати с иероглифами дождитесь загрузки шрифта.

Для пересчёта меток HSK 3.0 у слов используется `node update_hsk30.js /path/to/hsk30.csv /path/to/hsk30-expanded.csv`. Скрипт обновляет уровни в существующих уроках и не добавляет отдельные словари.
